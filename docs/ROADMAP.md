# Roadmap

## Phase 0
Repository, environment, GitHub, MongoDB, frontend/backend bootstrap. **Status:** bootstrap is present.

## Phase 1
Express + Mongoose + configuration + error handling + validation. **Status:** core configuration, health endpoint, error handling, and auth/profile validation are present; domain-specific validation and routes remain unfinished.

## Phase 2
Authentication and user profile. **Status:** OTP-based registration/login flow, cookie sessions, refresh/logout, and profile editing are implemented in the current code. OTP delivery uses a development-only simulator; no real SMS provider is connected, so production OTP delivery is unavailable.

## Phase 3
Transaction and category core. **Status:** not implemented; pages and backend modules remain placeholders, and routes are not registered.

## Phase 4
Budget and reminder. **Status:** not implemented; pages and backend modules remain placeholders, and routes are not registered.

## Phase 5
Reports and caregiver read-only. **Status:** not implemented; pages and backend modules remain placeholders, and routes are not registered.

## Phase 6
Accessibility, PWA and offline draft. **Status:** profile-level font-size and high-contrast settings exist; PWA and offline-draft work remain unfinished.

## Phase 7
Unit/API/E2E tests and usability testing. **Status:** unit/API and authentication UI tests exist; broader feature coverage and usability testing remain unfinished.

## Phase 8
Deployment, seed data, documentation and demo. **Status:** unfinished.
