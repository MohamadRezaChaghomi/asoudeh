# Asoudeh brand integration

## Assets and usage

| Asset | Purpose |
|---|---|

The supplied SVGs were parsed and checked for `viewBox`, scripts, event attributes, external references, CSS `url()`, raster `<image>` embeds, and `<foreignObject>`; none of those unsafe constructs were found. Raster files are locally generated by `frontend/scripts/export-assets.mjs`; it refuses to overwrite an existing output. No export step makes network requests. The social PNG is rendered with the locally installed Estedad font. The original root-level `frontend/public/og-image.svg` is retained; the preview copy is the wired source. The maskable mark stays inside the central 80% safe zone.

The supplied `frontend/public/scripts/export-assets.js` was reviewed and contained only a console message; it was not run and is retained under `docs/brand/reference/`. The functional local exporter is under `frontend/scripts/`.

## Logo component

`frontend/components/brand/BrandLogo.tsx` maps the five typed variants to SVGs and uses their exact viewBox dimensions. Full primary and horizontal logos are rendered as complete wordmarks; symbol-only white and monochrome variants retain the adjacent Persian label. An empty `alt` supports decorative use, and the default alt text is Persian.

## Typography and theme tokens

The application self-hosts variable Estedad through `next/font/local` with Arabic, Latin, and Latin Extended subsets, `display: swap`, and a system fallback. No external font requests are made. Supplied `frontend/public/tokens.css` values were merged into `frontend/app/globals.css` as theme-aware aliases; existing component token names are retained. The offline page uses system fonts only.

The UI keeps the supplied brand greens and neutrals while using contrast-adjusted text, focus, border, and dark-mode action tokens. Text is checked against the 4.5:1 normal-text threshold; focus indicators and meaningful control boundaries are checked against 3:1.

The horizontal and primary source SVGs, plus the OG source SVG, contain text with `font-family: Estedad`. They have not been rewritten; request outlined SVGs from the designer before using those sources where the local font is unavailable. The generated OG PNG is self-contained.

## Metadata and offline shell

`frontend/app/layout.tsx` declares favicon variants, Apple icon, and OG/Twitter metadata. `frontend/app/manifest.ts` references separate 192x192 and 512x512 general icons and the maskable 512x512 icon. Theme colors match the CSS tokens.

`frontend/public/sw.js` uses cache `asoudeh-static-shell-v6`, pre-caching only `/offline.html` and `/icons/app-icon.svg`. It does not cache authenticated pages or API responses. The offline page has a system-font stack and a retry link.

Brand documentation and reference mockups are under `docs/brand/`; they are not shipped from `public/`.

## Verification

- Frontend typecheck, lint, production build, and the four brand asset/contrast tests passed. The latest build's largest First Load JS bundle is 148 kB.
- The final production PWA test verified the v6 cache contains only `/offline.html` and `/icons/app-icon.svg`; it reported no CSP, self-hosted-font, or hydration errors.
- The broader app-shell/auth/public/responsive run was not fully green (20/31 passed). Focused reruns passed after fixing the brand logo locator and PWA notice interactions. Speech/auth failures from the broad run were not resolved or rerun as a suite.
