# Asoudeh brand assets

See [BRAND-GUIDELINES.md](./BRAND-GUIDELINES.md) for identity, usage, and typography guidance.

The application self-hosts Estedad. The offline page uses the system font stack. Raster exports are generated locally by `frontend/scripts/export-assets.mjs`; the maskable icon keeps its mark inside the central safe zone.

HTML mockups are retained as references in [mockups](./mockups/), outside the public asset directory.
