## Definition of Done
- Backend endpoint دارد.
- Validation دارد.
- Authorization/ownership بررسی شده.
- Frontend به API متصل است.
- Loading/Empty/Error state دارد.
- تست مسیر اصلی نوشته شده.
- روی موبایل بررسی شده.
- commit شده است.
