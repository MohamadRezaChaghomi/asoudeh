# Changelog

Notable project changes are recorded here. This log does not certify production readiness.

## [1.0.0] - 2026-11-23

### Added

- Persian RTL personal-finance flows for OTP sign-in, transactions, categories, monthly budgets, reminders, reports, and permission-scoped caregiver access.
- A consistent design system with responsive layouts, themes, and accessibility preferences.
- Public-page metadata, social sharing tags, structured data, sitemap, and robots rules.
- A guarded local demo-user seed for release validation, with sample transactions, budget, reminder, and caregiver relationship.

### Improved

- Consolidated project, architecture, API, operations, security, and academic documentation.
- Refactored shared date and domain helpers and removed verified unused code/assets.
- Added performance budgets and expanded automated coverage for accessibility, responsive layouts, security headers, authentication, and resilience.
- Reviewed the existing security and error-handling implementation; the review reported no actionable vulnerabilities.
